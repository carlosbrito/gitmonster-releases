# GitMonster — downloads

Instaladores e atualizações do **GitMonster**, um cliente Git para Windows.

## Baixar

Abra a [última versão](https://github.com/carlosbrito/gitmonster-releases/releases/latest) e baixe `GitMonster-Setup-<versão>.exe`.

## Aviso do Windows (SmartScreen)

O instalador ainda não tem assinatura de código, então na **primeira instalação** o Windows pode mostrar
"O Windows protegeu o computador". Clique em **Mais informações** → **Executar assim mesmo**.

As atualizações seguintes são feitas pelo próprio GitMonster: quando houver versão nova, ele avisa e você escolhe quando atualizar.

## Sobre este repositório

Aqui ficam só as versões publicadas (instalador, `latest.yml` e `.blockmap`, usados pelo atualizador do app). O código-fonte não fica aqui.
